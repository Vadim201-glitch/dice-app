# Помощник для настольной игры

Статус: требования и план согласованы.

## 1. Назначение

Офлайн-веб-приложение для одного игрока. Приложение бросает три кубика, автоматически находит лучшее размещение на поле, начисляет очки за три раунда и показывает итоговую награду.

## 2. Правила игры

Игровое поле 5×5:

```text
1 6 4 5 3
2 5 3 6 1
3 4 * 5 6
4 3 2 4 1
5 2 1 3 2
```

- Используются три обычных шестигранных кубика.
- В каждом раунде выполняется ровно один бросок.
- Каждый кубик используется один раз.
- Порядок кубиков не имеет значения.
- Кубик можно поставить на клетку с соответствующей цифрой или на центральную звезду.
- Звезда подходит для любой цифры.
- Все три кубика должны образовать линию из соседних клеток без пропусков.
- Разрешены горизонтальные, вертикальные и обе диагональные ориентации.
- Верхний левый и нижний правый углы являются счастливыми клетками.

Результат раунда:

- линии нет — 0 очков;
- есть подходящая линия — 1 очко;
- подходящая линия проходит через счастливый угол — 2 очка.

Приложение выбирает лучший возможный результат. Если есть несколько вариантов с одинаковым результатом, достаточно показать один из них.

Игра состоит из трёх раундов. Итоговая награда:

| Общая сумма очков | Награда |
| --- | --- |
| 0–1 | 0 монет, нет выигрыша |
| 2–3 | 1 монета |
| 4–5 | 2 монеты |
| 6 | 3 монеты |

Монеты не сохраняются между играми.

## 3. Пользовательский сценарий

1. Игрок открывает приложение и начинает новую игру.
2. Нажимает кнопку броска.
3. Приложение генерирует значения трёх кубиков.
4. Приложение находит лучшее размещение и подсвечивает три клетки линии.
5. Игрок видит очки текущего раунда и общий счёт.
6. Следующее нажатие кнопки выполняет бросок следующего раунда.
7. После третьего раунда появляется окно с итоговым счётом и наградой.
8. Нажатие «ОК» закрывает окно и начинает новую игру с нулевым счётом.

## 4. Обязательные функции первой версии

- генерация трёх случайных значений от 1 до 6;
- поиск лучшего размещения кубиков;
- подсветка найденной линии на поле;
- отображение значений кубиков;
- подсчёт очков текущего раунда;
- подсчёт общей суммы очков;
- отображение номера текущего раунда из трёх;
- итоговое окно с очками и количеством монет;
- сброс игры после нажатия «ОК»;
- работа без интернет-соединения после установки или загрузки приложения;
- фэнтези-оформление средствами CSS.

Не входят в первую версию: история бросков, аккаунты, сохранение монет, статистика, несколько игроков, сервер, база данных, музыка и звуки.

## 5. Интерфейс

Предлагаемая структура экрана:

- сверху — номер раунда, очки текущего раунда и общий счёт;
- в центре — поле 5×5 с подсветкой найденной линии;
- рядом или под полем — значения трёх кубиков;
- внизу — кнопка броска;
- после третьего раунда — модальное окно с итоговыми очками, наградой и кнопкой «ОК».

Визуальное направление — фэнтези: тематический фон, рамки, цвета, шрифты и оформление кубиков и поля. Звуки и сложные анимации не требуются.

## 6. Платформа и технологии

- PWA на HTML, CSS и JavaScript;
- без фреймворка;
- без сервера и базы данных;
- вся игровая логика выполняется локально;
- `manifest.json` и service worker обеспечивают установку и офлайн-режим.

## 7. Организация кода

- `board.js` — схема поля и линии из трёх клеток;
- `rules.js` — проверка размещений и расчёт результата;
- `game.js` — состояние игры, раунды и сумма очков;
- `ui.js` — отрисовка поля, кубиков, счёта и итогового окна;
- `styles.css` — фэнтези-оформление;
- `manifest.json` и service worker — PWA и офлайн-режим.

Алгоритм расчёта перебирает допустимые линии из трёх соседних клеток и проверяет, можно ли разместить на каждой линии выпавшие значения с учётом звезды. Сначала выбирается вариант на 2 очка, затем на 1; при отсутствии подходящей линии результат равен 0.

## 8. Этапы разработки

1. **Зафиксировать правила и тестовые случаи**
   - результат: набор однозначных правил и примеров;
   - проверка: варианты с линией, звездой, счастливым углом и без линии.

2. **Реализовать расчёт комбинаций**
   - результат: функция получает три значения и возвращает очки и клетки линии;
   - проверка: автоматические проверки основных комбинаций.

3. **Реализовать игровую логику**
   - результат: три раунда, накопление очков и расчёт награды;
   - проверка: прохождение игры из трёх бросков и проверка всех диапазонов награды.

4. **Создать интерфейс и оформление**
   - результат: поле, кубики, счёт, кнопка, итоговое окно и фэнтези-стиль;
   - проверка: пройти игровой сценарий как пользователь.

5. **Добавить PWA и офлайн-режим**
   - результат: приложение устанавливается и работает без сети;
   - проверка: открыть приложение, отключить интернет и выполнить игру целиком.

## 9. Критерии приёмки

- каждое значение кубика находится в диапазоне от 1 до 6;
- приложение использует все три кубика только один раз;
- учитываются только соседние горизонтальные, вертикальные и диагональные линии;
- центральная звезда подходит для любого значения;
- при наличии линии через счастливый угол начисляется 2 очка;
- при наличии нескольких вариантов выбирается результат с максимальным количеством очков;
- после трёх раундов сумма и награда соответствуют таблице;
- после нажатия «ОК» начинается новая игра с нулевым счётом;
- приложение полностью проходит игровой сценарий без интернет-соединения.

## 10. Нерешённые детали

Эти вопросы не блокируют начало разработки:

- рекомендуется использовать русский язык интерфейса;
- нужно выбрать способ публикации статических файлов для первоначальной установки PWA;
- при равных вариантах линия выбирается по фиксированному внутреннему порядку, без показа других вариантов игроку.
